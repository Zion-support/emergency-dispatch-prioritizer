# Emergency Dispatch Prioritizer

Prioritize, classify and route emergency calls and incidents with AI — severity scoring, unit recommendation and situational summaries for dispatch centers.

**Free & open-source (MIT).** Part of the [Zion AI App Network](https://ziontechgroup.com/zion-app-network/) — Batch 79: GovTech & Smart City AI.

## Features
- Real-time call classification and severity scoring
- Unit recommendation and optimal routing
- Duplicate/related incident detection
- Live incident summaries for responders
- Response-time analytics
